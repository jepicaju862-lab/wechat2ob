# WeChat2Ob 使用指南

适用版本：0.1.7，桌面测试版。只介绍开源插件；生产收件服务及安装包不在本仓库提供。

## 准备

需要 Obsidian 桌面版 1.11.4+ 和另行取得的兼容收件服务。服务必须已就绪并具有有效登录。
微信能力取决于上游实际支持，插件本身不能创建微信登录或读取完整聊天记录。

从同一 Release 复制 `main.js`、`manifest.json`、`styles.css` 到
`.obsidian/plugins/wechat2ob/`，重新加载并启用插件。更新时保留 `data.json`、`state/` 和密钥。

## 连接

本机已安装独立服务时，点击“自动连接本机服务”。Windows 读取
`%LOCALAPPDATA%/WeChat2ObInbox/connection.json`，macOS 读取
`~/Library/Application Support/WeChat2ObInbox/connection.json`。
只接受本产品标记及 `127.0.0.1` 地址，不自动读取其他服务的连接文件。

手动连接时填写服务地址并保存 API Token，再保存设置。默认端口为 7342；远程服务必须 HTTPS。
Token 只存于本设备 Obsidian SecretStorage。它用于允许读取消息，与插件开源许可无关。
同一个 ClawBot 不要同时运行两个上游轮询服务；复用已有服务时请手动连接，客户端进度独立。

## 输出设置

| 设置 | 默认值 / 行为 |
| --- | --- |
| Markdown | 开启，按消息接收日期写入日记 |
| 日记目录 | `日记`；文件名 `YYYY-MM-DD.md` |
| 指定文件 | 可改为固定 `.md` 文件，默认 `微信收件箱.md` |
| 时区 | `local`；可选 `Asia/Shanghai` 或其他 IANA 时区 |
| 附件与视图目录 | `WeChat2Ob`，需要空目录或本插件已有目录 |
| Bases | 开启，每个收件笔记一行 |
| `.duowei` | 默认关闭；可新建或映射已有可写表格 |
| 自动同步 | 初装关闭，自动本机连接成功后开启；默认间隔 3 秒 |

只启用 Bases 也需要写入 Markdown 笔记作为数据源。日记目录和指定笔记可以位于已有目录；
不自动读取核心日记插件的目录、模板或文件命名规则。

启用 `.duowei` 时单独指定目标路径，不能把表格路径填入 Markdown 设置。
已有表格先“选择已有文件 → 读取字段”，映射正文及其他需要的列并保存。
类型、状态可映射文本、长文本、单选或多选；选择列按名称匹配已有选项，不修改选项或字段。
缺少或重名选项会报错并保留消息重试。只读表、实时索引或不支持的格式不能写入。

更改设置后点击“保存设置”，再同步。更改路径或输出选项不会自动补写已经确认的历史消息。
插件只对自身的消息进度去重，不合并其他插件已写入的记录。

## 故障和数据安全

- “服务未就绪”：核对独立服务是否运行并已登录；本仓库不能替代服务安装或登录。
- HTTP 401/403：核对地址和 Token；不要把密钥贴到公开 Issue。
- 旧版“密钥 ID 无效”：升级后重新连接或保存 Token；不需要删除设置、客户端 ID 或进度。
- 目标路径错误：使用库内相对路径，不能包含隐藏目录、越界路径或系统保留名。
- 写入结果不确定：先检查笔记与私人日志，不要直接删除进度，否则可能重复写入。

附件每个最多 100 MB，并校验大小和 SHA-256。已成功输出保留，失败输出可重试；所有输出完成后才确认服务消息。
Markdown 只追加，不覆盖人工整理；已有映射表格首次写入前备份。仍建议自行备份库。
已移除历史补充和旧格式清理的界面入口，升级不主动迁移或重写旧笔记。

`state/` 含消息正文、附件信息和中断恢复内容，应按私人数据保护。
在公开反馈中只提交脱敏错误说明和合成示例，不上传完整配置、连接文件、消息数据库或用户附件。
